- **题目最优质检状态口径说明**：考虑终检未通过的题目存在专家返修之后静态质检也不过的可能，主办方决定按**在最终版质检规则下该题目的最优质检结果**进行结算；曾在最终版质检 SKill 下通过平台侧静态质检的题目，专家保底拿到折价验收的报酬。主办方以此鼓励大家继续参与终检返修，争取解锁全部金额；

<blockquote><p>最终版质检规则：于11月7日向全部专家同步的 <cite doc-id="ZK2ddy4YRozlWxxd6QUcx8KPnGe" file-type="docx" title="Skill修改清单与格式说明" type="doc"></cite>。</p></blockquote>

- **可以主动放弃返修**：考虑到专家做题精力以及时间预算，如果数据始终无法通过终检，专家可以**选择放弃返修**，主办方结束题目流转状态并将题目入库，并按照“最优质检结果”来结算金额；
- **没有返修次数限制**：不对流程中的题目有“返修次数”以及“终检次数”的限制，不因此而废弃题目；**所有题目最后一次返修提交的时间是在 12月1日 24:00 前**，主办方一般于提交 DDL 7天后返回质检结果（7天为预期估算值，以实际返回结果的日期为准）；

> 之前因**超出返修 ddl 被废弃的题目，依旧可以继续进行返修**，返修后满足验收政策的可以正常参与结算。

- **高产激励于最后一批结算**：因“高产大户”激励政策与每位专家“通过终检”的题目数有关，该项激励将于最后一批质检结束（12月8日 24:00）后，统一计算每位专家此项激励金额，并在**最后一批结算款项发放**；



# 专家确认流程

1. **查看题目公示表格**：Auto Research 项目官方唯一结算数据源<cite doc-id="UuOqbMBxCae9fdsu7e2cBjggnOf" file-type="bitable" table-id="tbltCUxO9l58WLTY" title="AutoResearch｜结算公示表格" type="doc" view-id="vewaBHqjsn"></cite>；
2. **检查题目的状态**：在题目列表页面核查“题目当前状态”以及“最优质检结果”；
3. **确定该题目是否要参与本期结算**：

   1. 专家不想继续返修，需要在表格中“是否选择结算”列选择“是”，题目会终止流转并进入结算流程；
   2. 专家想继续返修，可以先不用填写“是否选择结算”，该行题目信息随着下一次返修结果自动更新质检状态以及结算金额；
4. **核验本期题目结算总费用**：根据本期结算的题目，检查“专家结算金额”表的“结算金额”是否正确

   1. 若无误，“金额确认”列点击“确认”
   2. 如有异议，请在该列填写“否”并补充备注信息供平台方核实，平台方于 24h 内给出复核结果；

![图1. 确认金额并选择是否本期结算](https://feishu.cn/file/C2o1b4dIvoIUlkxW367cBgFVnPb)

1. **平台打款**：经专家确认结算且金额正确的题目，平台完成打款后会在题目列表中的“结算日期”更新，以区分该题目是否已完成结算；
2. **补充重跑 GPU 费用**：如重跑需要额外的 GPU 费用，专家需要在 GPU 报销列填写金额以及对应的重跑的 GPU 使用说明，平台审核通过的题目进入算力报销；

> 注：因重跑而再次申请算力报销，**专家只能在结算题目的时候一次性填写**，若平台审核通过，随题目费用一起报销。**最多申请重跑报销一次。**

![图2. 申请重跑算力补贴](https://feishu.cn/file/GUK5brMgOoqNjVxKZu4crk66nJd)

# 附录. 关于结算金额政策的详细说明
